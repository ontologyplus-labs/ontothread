# Research data notice

The MIT license covers project code and project-authored documentation. It does
not change ownership or grant additional rights in third-party filing content.
The retained research fixtures contain selected SEC filing excerpts with source
URLs and hashes, schema snapshots, blank assignment templates, and development
reference labels needed by the regression suite. They are not an independently
validated benchmark or a full reproduction of the original research archive.

The default UI demo contains selected real NVIDIA, AMD, and Broadcom SEC filing
excerpts, attributed development source reviews, and original filing links/hashes.
The local archive for this demo contains excerpt bytes, not complete original HTML;
API and UI metadata explicitly state that distinction. The demo is historical and
is not an independently validated benchmark or a live company model. See
`docs/real-demo.md` for its source manifest and reproduction method.

The optional `demo --synthetic` walkthrough uses fictional text and companies.
Full downloaded filings, private reviewer returns, credentials, and machine-local
runtime data are excluded from the release.
