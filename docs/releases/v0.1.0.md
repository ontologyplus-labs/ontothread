# OntoThread v0.1.0

OntoThread by OntologyPlus is a self-hosted research tool for connecting reviewed
claims across SEC filings and inspecting the evidence behind each relationship.

## Included

- Python 3.12+ package, `ontothread` CLI, FastAPI API, and browser workspace.
- SQLite setup and a Docker Compose stack with PostgreSQL and Neo4j.
- An offline real SEC excerpt demo with NVIDIA, AMD, Broadcom, TSMC, and Samsung.
  It includes five reviewed manufacturing claims and two candidates for explicit review.
- Bounded graph paths, supported research questions, passage search, exact source
  quotes, company identity resolution, and accepted/rejected candidate histories.
- Versioned ontologies, schema discoveries, evidence-linked proposals, review
  decisions, targeted reprocessing, and historical query cutoffs.
- A public TSMC advanced-packaging development case explaining the change from
  `finance-v2` to `finance-v3` and the resulting reviewed, cited relationship.
- MIT-licensed code and project documentation, with a separate filing data notice.

## Evidence and operation

The default demo contains four selected historical filing excerpts. It runs without
API keys, SEC requests, or model calls. Its development source reviews retain their
attribution. The TSMC ontology-evolution case is documented separately from the
default demo and uses records from the original research workspace.

CLI ingestion, passage comparison, and explicit review support updates from later
filings. Scheduled filing monitoring and automatic omission flags are future work.
An omitted disclosure leaves the earlier source evidence available for investigation.

The Python import package remains `fig`, `fig` is available as a CLI alias, and the
existing `/v1` endpoints, `FIG_*` settings, and persisted identities retain their meanings.
