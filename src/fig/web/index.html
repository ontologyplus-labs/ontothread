Get started Local setup, demo, and research workflow

1. Explore real SEC evidence

In your activated Python environment, run:

ontothread migrate
ontothread demo

With Docker, use docker compose exec api ontothread demo. Then select Refresh data. The demo loads real NVIDIA, AMD, and Broadcom filing excerpts, reviewed manufacturing relationships to TSMC and Samsung, and two source-backed proposals to review. It runs offline without an API key.

2. Bring SEC filings

Set SEC_USER_AGENT in your local .env to your app name and real contact email, then run:

ontothread ingest-sec --cik 1045810

Refresh data after ingestion. Select a company, search its filing, extract candidates, and review their exact quotes before accepting a relationship.

3. Configure optional models

Rule extraction works offline. To enable model extraction, set both OPENAI_API_KEY and FIG_LLM_MODEL in local configuration and restart the API.

Model calls require an explicit selection and may incur provider charges. Keep keys in server configuration.
